# OpenMiniPaints

A free, open REST API for miniature paint catalogs. Covers Citadel, Vallejo, AK Interactive (3rd Gen), Kimera, ProAcryl, and Army Painter.

Backed by [Convex](https://convex.dev). See `.prd/prd-v1.md` for the full product spec.

---

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Link to Convex (interactive — requires browser login)

```bash
npx convex dev --configure new --project open-mini-paints
```

This will:
- Prompt you to log in to the Convex dashboard (browser opens automatically)
- Create a new Convex project called `open-mini-paints`
- Write `CONVEX_URL` and `CONVEX_DEPLOYMENT` to `.env.local`
- Start the local dev server, watching `convex/` for changes

Keep this process running in a terminal while developing.

### 3. Deploy schema

The schema (`convex/schema.ts`) is pushed automatically by `convex dev`. For a one-shot deploy without the watcher:

```bash
npx convex deploy
```

## Generating an API Key

API keys are stored as SHA-256 hashes — the raw key is shown exactly once at creation time.

### Prerequisites

- Convex project is linked (step 2 above).
- `CONVEX_DEPLOY_KEY` is set. Export it from the [Convex Dashboard](https://dashboard.convex.dev) under **Settings → Deploy Keys**, then:

```bash
export CONVEX_DEPLOY_KEY=<your-deploy-key>
```

### Run the generator

```bash
npx tsx scripts/generate-key.ts <label>
```

Example:

```bash
npx tsx scripts/generate-key.ts "PaintTrackerLAH production"
```

Output:

```
========================================
  API key generated for: PaintTrackerLAH production
========================================

  Key (save this — it will NOT be shown again):

  a3f2...64 hex characters ...9c1

========================================
```

Store the key as `PAINT_CATALOG_API_KEY` in the consumer's environment. It cannot be recovered — if lost, generate a new one.

## Project Structure

```
convex/
  schema.ts         # catalogPaints + apiKeys tables
  apiKeys.ts        # internal mutation: createKey
  catalog.ts        # HTTP actions: search, list, lookup, brands  (ticket #2)
  admin.ts          # internal mutations: upsertPaint, bulkImport  (ticket #2)
  _generated/       # auto-generated by Convex CLI (gitignored)

scripts/
  generate-key.ts   # create an API key record, print raw key once
  scrape/           # one script per brand  (ticket #3)
  import.ts         # bulk-import curated JSON  (ticket #3)

data/
  scraped/          # raw JSON from scrape scripts (gitignored)
  curated/          # reviewed JSON ready for import

.prd/
  prd-v1.md         # product requirements
```

## API Endpoints (implemented in ticket #2)

All endpoints require the header `x-api-key: <key>`.

| Method | Path | Description |
|--------|------|-------------|
| GET | `/search?q=&brand=` | Full-text search, results grouped by brand |
| GET | `/brands` | List all brands with paint counts |
| GET | `/paints?brand=&type=&cursor=` | List paints with filters, paginated |
| GET | `/lookup?code=&barcode=` | Exact match by brandCode or barcode |
